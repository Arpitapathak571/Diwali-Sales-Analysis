# Diwali Sales Analysis

## 📌 Project Overview

This project analyzes Diwali sales data to understand customer purchasing behavior, sales trends, and factors affecting sales.

## 🎯 Objectives

- Analyze overall sales performance
- Understand customer demographics
- Identify high-performing product categories
- Analyze purchasing behavior based on gender, age group, occupation, and location
- Identify useful business insights from the sales data

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Analysis Performed

The project includes analysis of:

- Gender-wise sales
- Age-group-wise sales
- State-wise sales
- Occupation-wise sales
- Product category analysis
- Marital-status-wise sales
- Customer purchasing patterns

## 🔍 Key Insights

The analysis identifies customer segments, locations, occupations, and product categories that contribute significantly to Diwali sales.

## 🚀 How to Run

1. Clone the repository.
2. Open the Jupyter Notebook.
3. Install the required Python libraries.
4. Run the notebook cells to reproduce the analysis.
